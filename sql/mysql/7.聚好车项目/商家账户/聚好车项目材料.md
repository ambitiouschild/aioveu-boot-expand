## 1. 商家账户服务功能设计

### 核心功能点列表

- **商户主体管理**
  - 商户主体注册
  - 商户信息维护
  - 商户状态管理
- **角色权限体系**
  - 买家/卖家角色绑定
  - 角色权限配置
- **子账号管理**
  - 子账号创建/禁用
  - 子账号权限分配
  - 子账号登录控制
- **登录认证**
  - 多商户角色选择
  - 权限验证

### 核心关系处理

```
用户(User) --1:n--> 商户关联(UserMerchant) --n:1--> 商户主体(Merchant)
用户(User) --1:n--> 用户角色(UserRole) --n:1--> 角色(Role)
```

**权限控制逻辑：**

- 一个用户可关联多个商户主体
- 在每个商户主体下拥有特定角色（买家/卖家/管理员）
- 子账号继承父商户的权限范围但可细化

## 设计要点说明

1. **最小化原则**：仅实现商户账户核心功能，避免过度设计
2. **权限隔离**：通过商户ID+角色实现数据权限隔离
3. **灵活性**：支持一个用户多商户多角色场景
4. **可扩展**：角色权限体系支持后续细粒度权限控制

这样的设计既满足了当前需求，又为后续扩展留出了空间。
