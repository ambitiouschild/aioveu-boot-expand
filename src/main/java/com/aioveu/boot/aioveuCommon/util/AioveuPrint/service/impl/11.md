## 模板特点

1. **条形设计**：
   - 宽度80mm，高度30mm（标准水洗唛尺寸）
   - 左侧为二维码区域，右侧为文字信息
2. **信息布局**：
   - **二维码区域**：占据左侧1/3宽度
   - **衣物编码**：突出显示
   - **材质成分**：清晰展示
   - **洗涤图标**：使用图标直观展示洗涤说明
   - **洗涤说明**：详细文字说明
   - **原产国**：右下角显示
   - **品牌信息**：右上角显示
3. **响应式设计**：
   - 适应不同尺寸的二维码
   - 字体大小根据空间优化
4. **打印优化**：
   - 打印时隐藏边框
   - 添加打印时间信息
   - 显示总件数
